    38→Work Log:
    39→- Read worklog (Task 1 design-system foundation) and PRD §3–8 to lock the component contract before coding.
    40→- Created `src/lib/components/color-wheel/color-utils.ts` (308 lines): pure color math — `hsvToRgb` / `rgbToHsv` / `rgbToHex` / `hexToRgb` / `hsvToHsl` / `hslToHsv`, a `parseColor` that accepts hex / `rgb()` / `hsl()` / named colors / `{r,g,b}` / `{h,s,v}` / `{h,s,l}` objects, plus `formatHex`, `toColorOutput`, `clamp`, `clampHue`. No DOM, no side effects, no dependencies.
    41→- Created `src/lib/components/color-wheel/color-wheel-picker.ts` (1166 lines): the `ColorWheelPicker` class.
    42→  - Single `<canvas>` renderer; scoped CSS injected once per document (`#color-wheel-picker-styles`) with `--color-picker-*` custom properties for host overrides (marker borders, focus ring, background).
    43→  - Geometry: `innerR = size/2`, `wheelInnerR = innerR + wheelSpacing`, `wheelOuterR = wheelInnerR + wheelThickness`, `total = wheelOuterR * 2`, `cx = cy = total/2` — wheel stays centered on the inner shape.
    44→  - Hue mapping: 0° at top, clockwise; `angle = -π/2 + hue·π/180`; inverse `theta = atan2(dx, -dy)`.
    45→  - Hue wheel: 360 one-degree arc segments filled with `hsl(i, 100%, 50%)`. Cached as an offscreen canvas keyed by `(total, dpr)` so it only re-renders when geometry or DPR changes.
    46→  - Triangle: equilateral HSV triangle (A=top/white, B=bottom-right/pure hue, C=bottom-left/black). Per-pixel barycentric rendering with ~1px anti-aliased coverage. `V = α+β`, `S = β/V`.
    47→  - Square: inscribed square (`side = innerR·√2`) with 3 stacked gradients — pure hue → white-to-transparent (S) → transparent-to-black (V). Clipped to the square.
    48→  - Disk: polar mapping `r → S`, `θ → V = (1+cos θ)/2`. Smooth, seam-free; the tracked `diskTheta` field disambiguates the two θ values that map to the same V so the inner marker stays where the user dragged it.
    49→  - `none` mode: only the wheel + a solid filled inner circle in the current color; inner area is non-interactive.
    50→  - Inner-shape canvas cached per `(shape, total, dpr, hue)` so SV drags only redraw the cheap markers and hue drags only re-render the inner shape (not the wheel).
    51→  - Markers: hue marker = white-halo + dark-ring + pure-hue dot at the wheel mid-radius; inner marker = same triple-ring with the selected color in the center. Both stay perceivable against any hue/SV.
    52→  - Pointer interaction: `pointerdown` routes by radius (wheel ring vs inner circle vs gap); `setPointerCapture` for clean dragging; `pointermove` updates hue or SV continuously; `input` fires on every move, `change` on `pointerup`/`pointercancel`. Triangle drag clamps barycentric to ≥ 0 and renormalizes; square clamps to `[0,1]`; disk clamps radius.
    53→  - Keyboard: `ArrowLeft/Right` adjust hue by 1° (Shift = 10°); `Ctrl/Cmd+ArrowLeft/Right` adjust saturation; `ArrowUp/Down` adjust value (Shift = 10); `Home/End` wrap hue. Each key press emits `input` + `change`.
    54→  - Public API exactly matches the PRD contract: `constructor(container, options?)`, `setColor(color)`, `getColor()`, `setShape(shape)`, `setSize(size)`, `setHue(hue)`, `on/off(event, handler)`, `destroy()`. `setColor`/`setHue` accept programmatic updates and fire `input` + `change`. `setShape`/`setSize` preserve the current color (geometry-only changes).
    55→  - Tiny internal EventEmitter: `Map<string, Set<ColorHandler>>`. `emit` clones the handler set to a plain array so a handler unsubscribing during dispatch doesn't skip siblings; listener errors are caught and logged so a single bad handler can't crash the picker.
    56→  - `ResizeObserver` watches the canvas and refreshes the backing store + caches on DPR changes (e.g. window moved between monitors) — disconnected in `destroy()`.
    57→  - `destroy()` is idempotent: removes all pointer/keyboard listeners, releases pointer capture, disconnects the ResizeObserver, clears the handler map, removes the canvas from the DOM, drops the container class, clears the canvas, and nulls both offscreen caches.
    58→- Created `src/lib/components/color-wheel/index.ts` re-exporting the class, the `Shape`/`ColorPickerOptions` types, the `RGB`/`HSV`/`HSL`/`ColorOutput`/`ColorInput` types, and the color-math utilities.
    59→- Ran `bun run lint` — clean (0 errors, 0 warnings) after fixing two issues: replaced the `Function` type on `on`/`off` overloads with the explicit `ColorHandler = (color: ColorOutput) => void` to satisfy `@typescript-eslint/no-unsafe-function-type`, and removed an unused `eslint-disable-next-line no-console` directive. Ran `bunx tsc --noEmit` — no type errors in the new files (only unrelated pre-existing errors in `examples/` and `skills/`).
